Turning Waste Into Worth

Our Mission
Trash for Cash was created to encourage proper waste disposal by rewarding people with coins for every set number of recyclable items.

We believe environmental responsibility should be practical, measurable, and rewarding.
Why We Built This
Communities struggle with waste segregation and recycling participation. We designed an automated monitoring system powered by Arduino and database logging to make sustainability interactive and transparent.
Our Impact
✔ Encourages recycling habits
✔ Provides real-time monitoring
✔ Tracks coin rewards accurately
✔ Promotes environmental awareness
